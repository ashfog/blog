# ASHFOG Logo

The ASHFOG identity combines a circular signal mark with a custom path-based
wordmark. The five angled lines represent useful signals emerging through fog.

## Assets

- `ashfog-mark.svg` — standalone mark for light backgrounds
- `ashfog-mark-inverse.svg` — standalone mark for dark backgrounds
- `ashfog-logo.svg` — horizontal logo for light backgrounds
- `ashfog-logo-inverse.svg` — horizontal logo for dark backgrounds

All artwork is stored as SVG paths and shapes, with no external font dependency.

## Colors

- Ink: `#171816`
- Fog: `#F4F3EF`

## Usage

- Keep clear space around the logo equal to half the diameter of the mark.
- Use the standalone mark at 24 px or larger.
- Use the horizontal logo at 120 px wide or larger.
- Preserve the original proportions, stripe count, rotation, and colors.
- Do not add shadows, outlines, gradients, or additional rotation.
